# Происхождение материалов

При разработке использован прототип SIFT + Lucas–Kanade из
[skadibtw/CV_course/lab2](https://github.com/skadibtw/CV_course/tree/69f1251b3d0f986badcde2ce7ad74a137fc99779/lab2).
Класс трекера и цикл обработки переработаны: добавлены исходный четырёхугольник,
банк масштабов, уникальность соответствий, проверка покрытия, покадровые координаты,
отсутствие удержания устаревшей рамки, MP4/H.264 и воспроизводимый пакетный запуск.
Этот проект не выдаёт исходный прототип за независимую разработку с нуля.

Три видео mona-lisa*.avi взяты из test-videos того же репозитория и используются
как учебные тестовые материалы. Авторство и ссылка на источник сохранены.
Собственное видео my_video.mp4
предоставлено владельцем этого репозитория для данной лабораторной работы.

Дополнительно изучен [programmer1276/SKOI_LAB2](https://github.com/programmer1276/SKOI_LAB2/tree/928c4cbd7da0c1d8a7df49b8f1360f4cabd1c60c)
для сравнения ORB и принципов проверки гомографии. Код ORB в итоговый трекер не включён.
